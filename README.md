# Gwent-for-SUMI
A remake of the Gwent Minigame From The Witcher 3 designed for Xteink devices running SUMI

# How to install

Drop the file in your /custom/ folder on your xteink device running SUMI:

https://github.com/hellominecraft913-dev/Gwent-for-SUMI/blob/bfcae7fa7ed2a880f10e3f453cb214b285425f55/Gwent%20Minigame.lua

# How to open in LOVE

Simply double click the file with the latest version of the LÖVE game engine installed:

https://github.com/hellominecraft913-dev/Gwent-for-SUMI/blob/bfcae7fa7ed2a880f10e3f453cb214b285425f55/main.love
